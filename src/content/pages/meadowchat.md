# Meadowchat

  
  

  

Meadowchat is new and finding its feet.

But in theory it is the place where we can get things done while we are not together. it’s a bit like what’s app but elusively Meadowbrook and DRA related topics. 

You can join the topics you are interested and set how many notifications you get about each topic. If you want to find a file just search. It has todo lists, reminders and video meetings.

You’ll need a Meadowbrook account to access these spaces, and to have one of these you’ll already need to be part of the groups of trustees volunteers etc.. contact it@meadowbrookdartington.org to get one.

Once you have an account select a topic below to get started.
